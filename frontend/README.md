# Kojurebi — tienda

React + Vite + TypeScript + Tailwind + Zustand + Framer Motion.

Puerto **45321**. Vite envía `/api` y `/uploads` a `http://127.0.0.1:45322`.

```bash
npm install
npm run dev    # http://127.0.0.1:45321
npm test
npm run build
```

| Carpeta | Qué es |
| --- | --- |
| `src/pages/` | Pantallas (home, tienda, estudio, ficha, bolsa, admin) |
| `src/components/` | Marcos, stickers, mosaico, arte protegido |
| `public/brand/` | Cerezas y marca |
| `public/shop/` | Prints y stickers reales |
